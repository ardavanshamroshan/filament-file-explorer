Configuration

Publish
php artisan vendor:publish --tag=filament-file-explorer-config
KeyDescription
authorizerFQCN implementing FileExplorerAuthorizer
collectionSpatie media collection (default file-explorer)
upload.max_size_kbMax upload size
upload.allowed_extensionsAllowed extensions
folders.max_depthMax nested folder depth
folders.tableFolders table name
routes.prefixMedia route prefix
morph_classLegacy morph map when migrating from another folder package

Livewire 4 tip: register both dotted and :: component names are shipped — use @livewire('filament-file-explorer::file-explorer', …) or <livewire:filament-file-explorer.file-explorer />.
